1. Executive Abstract

Engineering students across universities face fragmented preparation tools when transitioning from academics to high-paying software engineering careers. The existing DKODER web interface (dkoder.co.in), while conceptually sound, suffered from low visual contrast, rigid layouts, and an absence of interactive feedback mechanisms.

This project delivers a production-grade frontend redesign of the DKODER ecosystem. Crafted with a sleek obsidian dark theme punctuated by DKODER's signature high-visibility yellow (#FEE715 / #F5D90A), the revamped platform unifies:

  • Immersive Homepage: High-impact hero typography, category breadcrumbs, dual CTA triggers, and interactive video-curriculum preview decks.
  • Interactive Learning Suite: Topic-wise coding challenges, company preparation paths (Google, Amazon, TCS), and mock tests with real-time code execution simulations.
  • Certification & Testing Engine: Timed MCQ skill evaluations with automated scoring and dynamic, verifiable digital credential generation.
  • Competitive Hackathon Arena: Real-time tournament countdown timer, 4 challenge domain cards, and interactive team registration modals.
  • Institutional University Portal: Placement analytics and an interactive MOU application workflow for college administrations.

2. Key Functional Modules

Interactive Learn Hub

Interactive coding questions with difficulty badges, compiler simulation with C++/Python/Java syntax support, and live stdout output.

Automated Certification

Built-in 5-question timed technical assessment. Instant score calculation with downloadable digital certificate for scores ≥ 70%.

Hackathon Arena

Grand Tournament deck with 2-column hero, live countdown clocks, challenge domain selector, and interactive registration modals.

University Partnerships (MOU)

Comprehensive college placement statistics, institutional perks, and a step-by-step MOU application form with feedback validation.

3. Architecture & Technology Stack

Layer Technology Implementation Highlights
Framework React 18 + Vite Modular component structure, fast hot module replacement, 6.49s build speed.
Language TypeScript Strict typing across navigation, assessment state, and modal controllers.
Styling Modular Vanilla CSS Custom design tokens, dark-mode variables, glassmorphic blur, 100% WCAG contrast.
Interactivity Lucide React + Framer Micro-animations on hover, smooth modal dialog transitions, responsive layouts.

4. Key Improvements Over Original Platform

  • High-Contrast Typography: Replaced low-contrast dark buttons with crisp white and gold interactive states for optimal legibility.
  • Client-Side Interactivity: Added functional assessment tests, code output simulation, and interactive registration flows rather than static brochure pages.
  • University Focus: Created dedicated corporate and college outreach pages to bridge placement cell requirements.
